# Система управления заявками на обслуживание оборудования

Прототип серверной части клиент-серверной системы управления заявками на монтаж и техническое обслуживание климатического и холодильного оборудования.

Проект разрабатывается в рамках выпускной квалификационной работы.

## Технологический стек

- **Язык программирования:** Kotlin 2.2.20
- **Платформа:** Spring Boot 3.5.6
- **Сборка проекта:** Gradle
- **База данных:** PostgreSQL
- **Работа с БД:** Spring Data JPA, Hibernate
- **Миграции БД:** Flyway
- **Документация API:** Swagger UI (OpenAPI)
- **Валидация данных:** Jakarta Bean Validation

## Текущие возможности

На данном этапе реализован прототип серверной части системы.

Сервер поддерживает:

- создание заявок на обслуживание оборудования;
- получение списка заявок;
- получение отдельной заявки по идентификатору;
- изменение статуса заявки;
- удаление заявки;
- сохранение данных в PostgreSQL;
- проверку входящих данных;
- централизованную обработку ошибок;
- версионирование структуры базы данных с помощью Flyway.

## REST API

Базовый адрес: `http://localhost:8081`

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/requests` | Получить список заявок |
| POST | `/api/requests` | Создать заявку |
| GET | `/api/requests/{id}` | Получить заявку по ID |
| PATCH | `/api/requests/{id}/status` | Изменить статус заявки |
| DELETE | `/api/requests/{id}` | Удалить заявку |

## Документация API

После запуска приложения интерактивная документация API доступна по адресу:

`http://localhost:8081/swagger-ui/index.html`

Swagger UI позволяет просматривать доступные методы API и отправлять запросы к серверу непосредственно из браузера.

## Основные компоненты

- Контроллер — обработка HTTP-запросов.
- Сервис — логика работы с заявками.
- Репозиторий — взаимодействие с PostgreSQL.
- Модели и DTO — представление данных.
- Обработка исключений — централизованное формирование ответов об ошибках.
- Flyway — управление миграциями базы данных.

SQL-миграции базы данных находятся в `src/main/resources/db/migration`.

## Требования для запуска

Перед запуском необходимы:

- JDK 21;
- PostgreSQL;

## Настройка базы данных

Создайте в PostgreSQL базу данных `maintenance_system`.

Параметры подключения задаются в локальном конфигурационном файле приложения `application-local.properties`.

Пример настроек:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/maintenance_system
spring.datasource.username=postgres
spring.datasource.password=YOUR_PASSWORD
```

Укажите собственные учётные данные PostgreSQL. Не публикуйте реальные пароли и другие секреты в репозитории.

Flyway автоматически применяет доступные миграции при запуске приложения. Hibernate проверяет соответствие структуры базы данных Kotlin-сущностям.

## Запуск приложения

Клонируйте репозиторий:

```bash
git clone https://github.com/Stilb0n/maintenance-system
```

Перейдите в каталог проекта:

```bash
cd MaintenanceSystem
```

Запустите сервер на Windows:

```bash
gradlew.bat bootRun
```

После успешного запуска сервер будет доступен по адресу:

`http://localhost:8081`
